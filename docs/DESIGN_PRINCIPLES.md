# InkdFrames Design Principles

## 1. S Pen First

The application is designed around stylus input before finger input.

## 2. Canvas First

The artwork should occupy as much screen space as possible.

## 3. Mobile Native

The experience should feel designed for a phone, not like desktop software squeezed onto one.

## 4. Non-Destructive

Nothing should permanently destroy artwork without confirmation.

## 5. Performance Matters

Smooth drawing always takes priority over visual effects.

## 6. Every Tap Counts

Reduce unnecessary taps wherever possible.

## 7. Professional Simplicity

Powerful enough for professionals.

Simple enough for beginners.
